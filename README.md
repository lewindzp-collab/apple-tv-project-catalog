# Apple TV Project Catalog

An original, Apple TV-inspired product and entertainment experience for a curated catalog of movies and series.

## Features

- Watch Now and category browsing
- Hero feature presentation
- Horizontal, TV-focused content rails
- Persistent Library
- Search across titles, genres and years
- Detail pages
- Profile chooser
- D-pad-friendly keyboard focus
- Responsive layout for TV and desktop
- Local state persistence

The project is an original interface concept. It does not copy Apple branding, proprietary artwork or authenticated Apple TV services.

## Run locally

Open `index.html` directly, or serve the folder:

```sh
python -m http.server 4173
```

Then open `http://localhost:4173`.
